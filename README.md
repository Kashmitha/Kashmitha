## 👨‍💻 About Me

I'm an **Associate DevOps Engineer at PortCity BPO**, passionate about cloud infrastructure, automation, DevSecOps, and modern software delivery.

I focus on building practical solutions that make infrastructure more reliable, deployments more repeatable, and security an integral part of the development lifecycle.

- ☁️ **Cloud Engineering:** Exploring scalable infrastructure on AWS and Azure.
- ⚙️ **DevOps & Automation:** Working with Terraform, Ansible, Docker, Kubernetes, and CI/CD pipelines.
- 🔐 **DevSecOps:** Learning and implementing security scanning, secrets management, and secure delivery practices.
- 📊 **Observability:** Exploring monitoring, logging, and alerting with tools such as Prometheus and Grafana.
- 💻 **Software Development:** Experience building applications with C#, ASP.NET Core, and React.
- 🎮 **Game Development:** Interested in creating interactive experiences with Unity and C#.

> **My engineering philosophy:** Automate repetitive work, build reliable systems, and integrate security from the beginning.
