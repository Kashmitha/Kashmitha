## About

I'm a DevOps practitioner building my experience in cloud infrastructure and application delivery. My goal is to make deployments repeatable, infrastructure easier to maintain, and security part of the development workflow.

- **Cloud & automation:** Developing practical skills in infrastructure as code, containers, and CI/CD through hands-on projects.
- **DevSecOps:** Deepening my understanding of vulnerability scanning, secrets management, and safer deployment workflows.
- **Reliability:** Exploring how metrics, logs, and alerts help diagnose issues and support dependable services.
- **Development background:** Experience with ASP.NET Core and React, with an ongoing interest in Unity game development.
